# Save Memory

Persist current session context to sidecar.

## Process

Update `index.md` with current session context (active project, profile, in-flight CRs, pending audits, recent decisions). Append meaningful events to `chronology.md`. Append distilled patterns to `patterns.md` if any cross-project insights emerged this session.

## Output

Confirm save with brief summary: *"Memory saved. {what was updated}."*
